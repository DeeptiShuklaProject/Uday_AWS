<InfoCard title="📘 Core Concept: What is a String?">
A string is a sequence of characters (letters, numbers, spaces, symbols) enclosed inside single (`'`) or double (`"`) quotes.
</InfoCard>

<TipCard title="💡 String Features & Methods">
1. **Indexing & Slicing**: Access characters by index (`text[0]`) or extract substrings (`text[0:5]`).
2. **Immutability**: Strings cannot be mutated in-place; string modifications create new objects in RAM.
3. **Concatenation (`+`)**: Joins multiple strings together into a single string.
4. **Built-in Methods**: Perform transformations using `.upper()`, `.lower()`, `.replace()`, and `.split()`.
</TipCard>

<KeyTakeaways>
1. Strings behave as immutable ordered character sequences.
2. Use slicing `[start:end]` to extract specific portions of text cleanly.
3. String methods return new transformed strings rather than mutating the original object.
</KeyTakeaways>

<SectionGuideCard sectionTitle="Quick Engineering Notes & Pitfalls Guide" motto="Review production best practices, performance optimization tips, and critical pitfall warnings." whatItDoes="Summarizes key engineering takeaways including Core Concept Overview, Pro Engineering Tips, and Common Pitfall Warnings." clickInstructions="Read through the InfoCard, TipCard, and WarningCard keynotes to prevent edge-case bugs and memory leaks in production code." badge="Summary Notes" />

<InfoCard title="Core Concept Overview">
Strings are immutable sequences of character code points encoded using UTF-8 or UTF-16 formats.
</InfoCard>

<TipCard title="Pro Engineering Tip">
Use `''.join()` for string concatenation inside loops to prevent O(N²) quadratic object creation overhead.
</TipCard>

<WarningCard title="Common Pitfall Warning">
Always specify UTF-8 encoding explicitly (`open('file.txt', encoding='utf-8')`) when reading text files to prevent platform-dependent decoding crashes.
</WarningCard>

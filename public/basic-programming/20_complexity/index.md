<InfoCard title="📘 Core Concept: What is Complexity Analysis (Big O)?">
Big O notation evaluates how an algorithm's execution time (**Time Complexity**) or RAM memory consumption (**Space Complexity**) scales as input data size (N) grows.
</InfoCard>

<TipCard title="💡 Common Big O Complexity Ranks">
1. **O(1) Constant Time**: Execution speed remains instant regardless of input size N (e.g., `arr[0]`).
2. **O(log N) Logarithmic Time**: Highly efficient growth rate (e.g., Binary Search).
3. **O(N) Linear Time**: Execution time grows proportionally with data size N (e.g., single loop over list).
4. **O(N^2) Quadratic Time**: Execution time grows squared with data size (e.g., nested loops).
</TipCard>

<KeyTakeaways>
1. Big O measures how performance scales as dataset size N increases.
2. O(1) and O(log N) represent optimal performance for enterprise applications.
3. Avoid nested loops (O(N^2)) on large datasets to prevent performance bottlenecks.
</KeyTakeaways>

<InfoCard title="📘 Core Concept: What is Exception Handling?">
Exception handling provides a safety net that catches runtime errors while a program is running, preventing the application from crashing unexpectedly.
</InfoCard>

<TipCard title="💡 Exception Handling Mechanics">
1. **Runtime Error**: An error occurring during execution (e.g., division by zero, invalid input).
2. **`try` Block**: Encloses code lines that might potentially trigger a runtime exception.
3. **`except` Block**: Executes fallback recovery code when a specific exception occurs.
4. **`finally` Block**: Code that runs unconditionally (e.g., cleanup tasks) regardless of success or failure.
</TipCard>

<KeyTakeaways>
1. `try-except` blocks prevent unexpected program crashes by handling errors gracefully.
2. Catch specific error types (e.g. `ValueError`, `ZeroDivisionError`) for precise debugging.
3. Use `finally` to ensure resources (like open files or connections) are always closed safely.
</KeyTakeaways>

<InfoCard title="📘 Core Concept: What is an Algorithm?">
An algorithm is a step-by-step set of instructions or computational procedure designed to solve a specific problem or process data.
</InfoCard>

<TipCard title="💡 Common Search & Sort Algorithms">
1. **Linear Search**: Checks each item sequentially one by one from start to end.
2. **Binary Search**: Fast search on sorted lists that repeatedly cuts search range in half.
3. **Bubble Sort**: Simple sorting algorithm that repeatedly compares and swaps adjacent out-of-order items.
4. **Efficiency**: Choosing the right algorithm dramatically reduces computation time on large datasets.
</TipCard>

<KeyTakeaways>
1. Linear Search works on unsorted lists; Binary Search requires data to be sorted first.
2. Binary Search is significantly faster than Linear Search on large datasets.
3. Sorting organizes data to enable fast searching and analysis operations.
</KeyTakeaways>

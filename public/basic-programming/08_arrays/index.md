<InfoCard title="📘 Core Concept: What is an Array / List?">
An array (or list) is an ordered collection of elements stored under a single variable name in computer memory, accessible via numerical positions (indexes).
</InfoCard>

<TipCard title="💡 Essential Array Operations">
1. **Zero-Based Indexing**: Elements are accessed by position starting at index `0` (e.g., `items[0]`).
2. **Contiguous Storage**: Array elements are arranged sequentially in RAM for fast index lookups.
3. **Array Mutation**: Append new items (`.append()`), remove items, or overwrite elements by index.
4. **Length (`len`)**: Returns the total number of stored elements inside the collection.
</TipCard>

<KeyTakeaways>
1. The first element in an array is always at index `0`, and the last element is at `len - 1`.
2. Arrays store multiple related items in a single manageable data structure.
3. Use loops to iterate over array elements efficiently.
</KeyTakeaways>

## 💡 Quick Engineering Notes & Pitfalls

<SectionGuideCard sectionTitle="Quick Engineering Notes & Pitfalls Guide" motto="Review production best practices, performance optimization tips, and critical pitfall warnings." whatItDoes="Summarizes key engineering takeaways including Core Concept Overview, Pro Engineering Tips, and Common Pitfall Warnings." clickInstructions="Read through the InfoCard, TipCard, and WarningCard keynotes to prevent edge-case bugs and memory leaks in production code." badge="Summary Notes" />

<InfoCard title="Core Concept Overview">
Arrays store ordered elements in contiguous memory blocks, granting O(1) random index lookups.
</InfoCard>

<TipCard title="Pro Engineering Tip">
Use `collections.deque` when inserting or deleting elements from the start of a list to avoid O(N) memory shift penalties.
</TipCard>

<WarningCard title="Common Pitfall Warning">
Avoid mutating a list (adding/removing items) while iterating over it in a `for` loop to prevent skipped elements.
</WarningCard>

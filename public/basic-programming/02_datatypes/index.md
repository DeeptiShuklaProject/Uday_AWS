<InfoCard title="📘 Core Concept: What is a Data Type?">
Data types tell the computer what kind of data a variable is storing. This enables the CPU to reserve the correct amount of RAM bytes and enforce allowed operations (like math vs text concatenation).
</InfoCard>

<TipCard title="💡 Primary Primitive Types Overview">
1. **Integers (`int`)**: Whole numbers without decimals (e.g., `10`, `-5`, `0`).
2. **Floating-Point (`float`)**: Real numbers with fractional decimal points (e.g., `3.14`, `19.99`).
3. **Booleans (`bool`)**: Logical flags (`True` or `False`) used in conditional branching.
4. **Strings (`str`)**: Character sequences enclosed in single or double quotes (e.g., `"Hello"`).
</TipCard>

<KeyTakeaways>
1. Integers store whole numbers; floats handle decimal values with floating-point precision.
2. Booleans drive control-flow decision making in conditional expressions.
3. Python auto-detects types dynamically, while statically-typed languages require explicit type declarations.
</KeyTakeaways>

## 💡 Quick Engineering Notes & Pitfalls

<SectionGuideCard sectionTitle="Quick Engineering Notes & Pitfalls Guide" motto="Review production best practices, performance optimization tips, and critical pitfall warnings." whatItDoes="Summarizes key engineering takeaways including Core Concept Overview, Pro Engineering Tips, and Common Pitfall Warnings." clickInstructions="Read through the InfoCard, TipCard, and WarningCard keynotes to prevent edge-case bugs and memory leaks in production code." badge="Summary Notes" />

<InfoCard title="Core Concept Overview">
Data Types define how binary bits in computer memory (RAM) are structured, interpreted, and manipulated by the CPU.
</InfoCard>

<TipCard title="Pro Engineering Tip">
Always convert user inputs explicitly using int() or float() before performing arithmetic math operations to avoid TypeError bugs.
</TipCard>

<WarningCard title="Common Pitfall Warning">
Be cautious of floating-point comparison bugs (`0.1 + 0.2 == 0.3` evaluates to False). Use math.isclose() or Decimal for monetary calculations.
</WarningCard>

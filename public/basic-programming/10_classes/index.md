<InfoCard title="📘 Core Concept: What is a Class & Object?">
A **class** is a blueprint or template for creating objects. An **object** is an active instance created from that blueprint containing real attributes (data) and methods (behaviors).
</InfoCard>

<TipCard title="💡 Object-Oriented Blueprint Features">
1. **Blueprint Analogy**: A class is like an architectural plan; an object is the physical house built from it.
2. **Attributes**: Variables attached to an object that hold its internal state (e.g., `color`, `speed`).
3. **Methods**: Functions defined inside a class that perform actions on object attributes.
4. **Constructor (`__init__`)**: Automatically initializes an object's starting data when created.
</TipCard>

<KeyTakeaways>
1. A class defines the template; objects are individual instantiated instances of that template.
2. Attributes store data state; methods define operational behaviors.
3. `self` refers to the current object instance inside class method definitions.
</KeyTakeaways>

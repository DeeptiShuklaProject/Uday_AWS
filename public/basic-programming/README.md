# Basics of Programming (Visual & Interactive Learning Engine)

Welcome to the **Basics of Programming** documentation module. This module provides a language-independent, visual-first foundation for mastering computer science and programming concepts.

## Supported Languages
- Python
- Java
- JavaScript
- C
- C++
- C#
- Go
- Rust
- Kotlin
- Swift

## Key Interactive Components
- **Monaco Playground**: Multi-language code editor with live syntax highlighting and execution.
- **Memory Visualizer**: Call stack and heap memory allocation visualizer.
- **Variable Animation**: Step-by-step variable mutation and reference copying animation.
- **Code Execution Player**: Line-by-line step execution with live variable inspection.
- **Flowchart Engine**: Interactive decision tree and loop flowchart renderer.
- **Language Comparison Matrix**: Side-by-side syntax comparison across 10 programming languages.

<InfoCard title="📘 Core Concept: What are Collections?">
Collections are specialized data structures (Dictionaries, Sets, Tuples) designed to store, manage, and search groups of data efficiently.
</InfoCard>

<TipCard title="💡 Collection Types Overview">
1. **Dictionary (`key: value`)**: Stores key-value pairs for instant O(1) lookups by key name.
2. **Set**: Unordered collection of unique items that automatically filters out duplicate entries.
3. **Tuple**: An immutable (non-modifiable) sequence of values.
4. **Efficiency**: Choosing the right collection structure optimizes memory and search performance.
</TipCard>

<KeyTakeaways>
1. Dictionaries provide fast lookups using custom keys instead of numerical indexes.
2. Sets automatically enforce uniqueness by discarding duplicate values.
3. Tuples protect data integrity by preventing modifications after creation.
</KeyTakeaways>

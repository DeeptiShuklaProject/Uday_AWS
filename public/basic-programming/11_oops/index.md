<InfoCard title="📘 Core Concept: What is Object-Oriented Programming (OOP)?">
Object-Oriented Programming (OOP) is a software design structure organized around real-world objects and classes rather than unstructured standalone functions.
</InfoCard>

<TipCard title="💡 The 4 Pillars of OOP">
1. **Encapsulation**: Bundles attributes and methods inside a class while protecting internal state.
2. **Inheritance**: Allows child classes to inherit attributes and methods from parent classes.
3. **Polymorphism**: Enables different classes to implement custom versions of the same method.
4. **Abstraction**: Hides complex internal execution details behind clean public interfaces.
</TipCard>

<KeyTakeaways>
1. Inheritance eliminates duplicate code by sharing parent class capabilities.
2. Polymorphism allows child classes to override parent methods with custom implementations.
3. Encapsulation protects sensitive object data from unintended external modification.
</KeyTakeaways>

<InfoCard title="📘 Core Concept: What is a Variable?">
Think of a variable as a labeled storage box in computer RAM memory. You store a value inside the box, assign it a human-readable name, and access or update that value as your program executes.
</InfoCard>

<TipCard title="💡 How Variables & Memory Work">
1. **Symbolic Alias**: A variable name acts as an alias for a physical RAM offset address (e.g., `0x7FFF1`).
2. **Assignment Operator (`=`)**: Stores or assigns a value into the variable's RAM memory slot.
3. **Mutability**: Variable values can be updated or mutated dynamically during execution runtime.
4. **Variable Scope**: Variables exist within designated code blocks (functions/loops) and clear when execution exits.
</TipCard>

<KeyTakeaways>
1. Declaring `age = 20` allocates RAM space and initializes `age` to `20`.
2. Reassigning `age = 21` overwrites the existing memory location with the new value `21`.
3. Choose clear variable names (`user_age`, `total_price`) to maintain readable enterprise code.
</KeyTakeaways>

# Level 6: Object-Oriented Programming (OOPs) & Class Inheritance (Heritage) 🤖🧬

Welcome to **CodeAdventure Level 6**! 🎮

In this level, you will master **Classes, Objects, and Class Inheritance (Heritage)** by creating hero battle mechas!

---

### 💡 What is Class Inheritance (Heritage)?
- **Parent Class (`BaseMecha`)**: Defines common attributes (`name`, `hp`, `attack_power`) and basic methods (`attack()`).
- **Child Class (`HeavyMecha` - Heritage)**: Inherits all parent properties using `super()` and adds specialized child features (`shield_power`).
- **Object Instantiation**: Creating a live object instance `hero = HeavyMecha("Titan-X", 120, 85, 40)`.

---

### 🎮 Mission Objective:
Construct a `BaseMecha` parent class and a `HeavyMecha` child class (Heritage), instantiate your hero object `Titan-X`, and invoke `hero.attack(boss)` to destroy `GlitchOverlord`!

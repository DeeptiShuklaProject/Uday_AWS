# CodeAdventure Documentation Repository

**CodeAdventure** is an interactive, multi-language coding arcade integrated into AuraDocs. It enables developers to learn programming in **11 languages** (Python, JavaScript, TypeScript, Java, C++, C#, Go, Rust, Bash, Ruby, PHP) by solving interactive sci-fi game puzzles inspired by CodinGame.

## Supported Levels
1. **01_onboarding**: Target Closest Enemy (CodinGame Onboarding)
2. **02_the_descent**: Mountain Altitude Laser Scanning
3. **03_mars_lander**: Velocity & Thruster Physics Control
4. **04_shadows_of_knight**: 2D Binary Search Radar Navigation
5. **05_power_of_thor**: 2D Vector Direction Movement

## Component Architecture
All game visualizers are driven by `CodeAdventureGame.jsx` and `adventure_config.json` with 1000% component reusability and zero hardcoding.

# ✍️ Nishant's Notes

## Add your first note

This section is yours. Drop any `.md` file into `doc_nishant_notes/` and it becomes a chapter here — the filename becomes the chapter title (`my-ideas.md` → "My Ideas"). Then run:

```bash
node scripts/convert-docs.mjs
```

All widgets work — `<Quiz>`, `<ConceptCard>`, mermaid diagrams, terminal fences, `![img](screenshots/x.png)` (put images in `doc_nishant_notes/screenshots/`).

Delete this file once your own notes are in.
